# 碰到什么就和什么结婚

适用于星露谷物语 1.6.15 的单人挑战模组，需要 SMAPI 4.4.0 或更高版本。

## 安装

1. 安装 SMAPI。[SMAPI 官网](https://smapi.io/)
2. 从 [GitHub Releases](https://github.com/fantasy-box/MarryOnTouch/releases/latest) 下载并解压 MarryOnTouch 的 ZIP 发布包，把其中的 `MarryOnTouch` 文件夹放进游戏目录的 `Mods`。更新时替换原来的同名文件夹。
3. 用 SMAPI 启动游戏，进入单人存档。

## 玩法

- 玩家移动时撞到 NPC、动物、家具、围栏、掉落物、作物、树木、草丛或镇上的垃圾桶，会进入原版广场婚礼。刚碰到的对象会作为婚礼演员出现在主角旁边。
- 树木、灌木、家具等按放在地上时的原版尺寸出现在舞台上。镜头会为大型对象和宾客留出空间。
- 玩家站着被走过来的 NPC 撞到，也会和该 NPC 举行婚礼。使用工具、与 NPC 对话、开箱、翻垃圾桶和自动拾取都可以正常进行。
- 婚礼对白自动继续，也可以点右下角的原版跳过按钮。播完或跳过后，画面保持黑屏，游戏在后台重读当天早上 6:00 的存档，恢复当天的物品、金钱和世界状态。安全地过夜后，次日照常保存。
- 新农场第一次能操作时会提前写入首日早晨的初始存档，供第一天循环使用。起床和换图时已经重叠的对象，需要先离开再碰到才会触发。
- 起床时可以直接走离床位，离开后再回到床上会照常询问是否睡觉。床、墙体、地形边界和普通地图贴图没有婚礼触发。垃圾桶通过地图的垃圾桶标记识别，独立放置的对象按实体识别。

## 游戏内复测

1. 新建未婚的单人存档，走出床位后撞墙，再撞一件其他室内家具或开局礼物盒。床和墙体应无反应，撞到的对象应以原来的外观出现在主角身旁，刘易斯和台下宾客应正常出现。散场后应回到第一天 6:00。
2. 隔一格砍树、锄地、浇水和收获。确认工具照常生效，掉落物飞进背包时也可以继续玩。再试着和 NPC 对话、开箱及翻垃圾桶。
3. 站在 NPC 的行走路线上，等 NPC 撞到主角。确认即使玩家没有按移动键，也会和撞到自己的 NPC 举行婚礼。再主动撞向草丛或垃圾桶，确认婚礼后撤销当天的变动。
4. 婚礼散场到当天清晨载入之间应保持黑屏。回档后从床位向右走，确认可以直接走开。离开后再回床上，确认选择「否」后还能移动，选择「是」后日期照常推进。

## 从源码构建

安装 .NET 6 SDK，运行下面的命令。也可以把 `GamePath` 指向对应版本的参考程序集。[星露谷和 SMAPI 参考程序集](https://github.com/StardewModders/mod-reference-assemblies)

```powershell
dotnet build -c Release "-p:GamePath=你的星露谷游戏目录"
```

将 `bin/Release/net6.0` 下的 `MarryOnTouch.dll` 和 `manifest.json` 一起放进 `Mods/MarryOnTouch`。
